# ADR-0002: 앱인토스 콘솔에 비게임 카테고리로 등록한다

- 상태: Accepted
- 날짜: 2026-11-02

## 맥락 (Context)

해달해달은 방치형 앱테크 앱으로, 무기 강화·동료 추가로 채굴 속도를 높이는 게임적 요소가 있다.
앱인토스는 게임/비게임 카테고리에 따라 프로모션(토스 포인트 지급) 정책이 다르다.

- 게임: SDK 함수 `grantPromotionRewardForGame`으로만 지급, 게임 결과(점수·승패·등수) 기반 보상 금지, 확률형·랜덤 보상 금지
- 비게임: SDK 함수 `grantPromotionReward` 또는 파트너 서버 API(Server-to-Server) 지급 가능, 이벤트 참여형(설문·퀴즈·간단한 미션) 프로모션 허용

## 결정 (Decision)

앱인토스 콘솔에 **비게임** 카테고리로 등록한다.

## 결과 (Consequences)

- 서버를 통한 토스 포인트 지급(무결성 확보)이 가능하다.
- O/X 퀴즈 같은 이벤트 참여형 보상을 설계할 수 있다.
- 리스크: 무기 강화·동료 등의 요소 때문에 검수에서 게임물로 분류될 가능성이 있다. 게임물로 분류되면 서버 지급 방식과 일부 프로모션 유형을 쓸 수 없으므로, 출시 전 앱인토스에 분류 기준을 문의한다.
- 강화 성공 확률 등 확률형 요소를 토스 포인트 지급과 연결하지 않는다.
