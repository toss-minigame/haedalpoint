# ADR-0007: 물고기는 해달 낚시로만 얻고, 해먹 → 창고 → 토스 포인트 순서로 흐른다

- 상태: Accepted (구조 확정. 해먹 용량·강화 단계 등 수치는 임시값)
- 날짜: 2026-11-02
- 대체 대상: ADR-0005 (퀴즈 보상으로 물고기를 지급하던 결정을 대체한다)

## 맥락 (Context)

해달해달은 방치형 앱테크 앱이다. 사용자가 광고를 소비한 만큼 토스 포인트를 받고,
그 과정이 "해달이 물고기를 잡는다"는 하나의 경험으로 이어져야 한다.

ADR-0005는 O/X 퀴즈 정답 후 광고를 보면 물고기를 바로 지급하기로 했다.
이렇게 하면 물고기를 얻는 경로가 낚시·퀴즈·출석으로 흩어지고, 월 지급액을 예측하기 어렵다.

예산 제약은 다음과 같다.

- 사용자 한 명이 한 달에 받을 수 있는 토스 포인트는 **최대 5,000원**이다.
- 강화 없이 한 달 내내 낚시하면 **1,000원**을 받는 수준으로 맞춘다 (임시 기준).
- 물고기 → 토스 포인트 전환 비율은 매월 콘솔에 보고하는 값이므로 고정한다.

## 결정 (Decision)

### 1. 물고기는 해달 낚시로만 얻는다

퀴즈·출석은 물고기를 주지 않는다. 대신 **낚시 속도**를 올려준다.

```
콘텐츠(O/X 퀴즈 등) ─광고 시청→ 낚싯대 강화 +10% ┐
출석 1~6일차 ─────────────→ 낚싯대 강화 +10% ├→ 낚시 속도
출석 7일차 ──→ 해달 친구 (속도 +100%, 해먹 용량 +50%) ┘
해달 낚시 → [해먹: 용량 한도] ─저장→ [창고: 영속] ─전환→ 토스 포인트
```

- **해먹**: 해달이 잡은 물고기가 쌓이는 곳. 용량이 차면 더 잡지 않는다. 앱을 꺼둔 동안에도 쌓인다.
- **창고**: 사용자가 해먹에서 옮긴 물고기를 보관하는 곳. 여기 있는 물고기만 영속 재화다.
- **토스 포인트 전환**: 창고의 물고기를 전환한다 (후속 작업).

### 2. 수치

| 항목 | 값 | 비고 |
|---|---|---|
| 전환 비율 | 물고기 500마리 = 토스 포인트 1원 | 확정 |
| 기본 속도 | 강화 0단계로 30일 낚시 = 1,000원 (시간당 약 694마리) | 임시 |
| 낚싯대 강화 | 단계당 기본 속도의 +10% (복리 아님) | 단계 수 임시 |
| 해달 친구 | 속도 +100%, 해먹 용량 +50% | 해먹이 더 빨리 차서 더 자주 들어와야 한다 |
| 보너스 합산 | 더하기 (예: 강화 3단계 + 해달 친구 = 1 + 0.3 + 1.0 = 2.3배) | |
| 초기화 | 강화와 해달 친구는 매일 KST 자정에 풀린다 | 해달 친구는 7일차 출석한 날 자정까지 |
| 해먹 용량 | 마리 수로 고정 (임시 5,000마리) | 언제든 바꿀 수 있어야 한다 |

### 3. 구현 원칙

- 물고기 수량은 **서버가 시간으로 계산**한다. 클라이언트가 보낸 수량은 믿지 않는다.
- 수치는 `apps/api/src/common/globals/fishing.policy.ts` 한 곳에만 둔다. 바꾸면 api만 재배포한다.
- 월 상한을 코드로 강제하지 않는다. 대신 **최악의 경우(31일 내내 최대 강화 + 해달 친구 5일)가
  5,000원을 넘으면 실패하는 테스트**로 정책값을 지킨다.

## 결과 (Consequences)

- 퀴즈 보상은 물고기 대신 낚싯대 강화가 된다. `quiz_attempts.reward_amount` 컬럼을 삭제한다.
- 출석 1~6일차 보상(`ENHANCE_BONUS`)은 모두 +1단계(+10%)가 된다. 7일차(`OTTER_FRIEND`)는 해달 친구를 부른다.
- 해먹이 가득 차면 푸시로 알린다 (후속 작업). 앱인토스 정책상 기능성 메시지로만 보낼 수 있고,
  재방문 유도 문구는 쓸 수 없으며, 문구 검수와 알림 동의문이 필요하다. 야간(21~08시)에 가득 차면 08시로 미룬다.
- 창고 적립 이력(`warehouse_ledger`)의 합계가 매월 콘솔에 보고할 물고기 발행 총액이 된다.
- '자체 포인트' 프로모션 정책은 ADR-0005와 같이 그대로 적용된다.
- 설계 상세: [docs/design/fishing.md](../design/fishing.md)
