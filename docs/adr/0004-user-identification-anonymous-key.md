# ADR-0004: 사용자 식별에 익명키를 사용한다

- 상태: Accepted
- 날짜: 2026-11-02

## 맥락 (Context)

서버는 사용자별 물고기 잔액·참여 이력을 관리하고, 프로모션 API로 토스 포인트를 지급해야 한다.
앱인토스 프로모션 API는 다음 두 방식 중 하나로 지급 대상을 식별한다.

- `x-toss-user-key`: 토스 로그인으로 받은 `userKey`. 콘솔 `TOSS_LOGIN` 약관과 로그인 연동이 필요하다.
- `x-anon-key`: SDK `getAnonymousKey()`로 발급받은 hash. 로그인 없이 사용자를 식별할 수 있다.

## 결정 (Decision)

사용자 식별에 **익명키**(`getAnonymousKey` → 서버에서 `x-anon-key` 헤더)를 사용한다.

## 결과 (Consequences)

- 별도 로그인 화면·토스 로그인 연동 없이 사용자를 식별할 수 있다.
- 서버는 익명키 hash를 사용자 ID로 사용한다.
- 클라이언트가 보낸 hash는 위조될 수 있으므로, 서버에서 앱인토스 식별키 검증 API로 확인한 뒤 적립·전환을 처리한다.
- 이름·이메일 등 회원 정보는 받을 수 없다.
- 확인 필요: 앱인토스 프로모션 가이드에는 "서버로 프로모션을 지급하려면 토스 로그인을 구현해야 한다"는 문구가 있어, `x-anon-key`를 허용하는 API 문서와 상충한다. 앱인토스 문의로 확정하고, 토스 로그인이 필요하다고 답변받으면 새 ADR로 이 결정을 대체한다.
