# ADR-0005: O/X 퀴즈 보상을 앱 내 재화로 지급하고 토스 포인트로 전환한다

- 상태: Superseded by ADR-0007
- 날짜: 2026-11-02

## 맥락 (Context)

O/X 퀴즈 기능은 사용자가 퀴즈를 풀고 보상형 광고를 시청하면 보상을 받는 기능이다.
보상 방식에는 두 가지 선택지가 있다.

- A안: 퀴즈 참여·광고 시청 시 토스 포인트를 즉시 지급
- B안: 퀴즈 참여·광고 시청 시 앱 내 재화(물고기)를 지급하고, 이후 사용자가 토스 포인트로 전환

## 결정 (Decision)

**B안**을 채택한다. 퀴즈 참여·보상형 광고 시청 완료(`userEarnedReward` 이벤트) 시 물고기를 적립하고,
사용자 요청 시 물고기를 토스 포인트로 전환한다.

## 결과 (Consequences)

- 퀴즈 보상이 채굴·강화 등 앱의 핵심 루프(물고기 경제)와 연결된다.
- 앱인토스 '자체 포인트' 프로모션 정책을 적용받는다.
  - 자체 포인트 프로모션을 포함한 전체 프로모션 예산의 월별 합산이 1억 원을 초과할 수 없다.
  - 매월 말 물고기 발행 총액, 단위, 토스 포인트 전환 비율을 콘솔에 입력해야 한다.
  - 프로모션 등록 시 자체 포인트 여부를 표시한다.
- 서버에 물고기 원장(적립·차감 이력)과 전환 처리(잔액 확인 → 차감 → 프로모션 API 지급 → 결과 확인)가 필요하다.
- 광고 클릭은 보상 조건으로 쓸 수 없고, `userEarnedReward` 이벤트만 보상 신호로 사용한다.
- 미결정: 물고기 → 토스 포인트 전환 비율과 최소 전환 단위 (매월 보고 대상이므로 고정값을 권장한다)
