# ADR-0001: 앱 이름을 '해달해달'로 정한다

- 상태: Accepted
- 날짜: 2026-11-02

## 맥락 (Context)

프로젝트 초기 세팅 시 `package.json`의 이름은 `haedalpoint`로 되어 있었다.
앱인토스 프로모션 정책상 앱 내에서 '포인트'라는 명칭은 토스 포인트로 오인될 수 있어
사용이 제한되므로, '포인트'가 들어간 앱 이름은 검수에서 문제가 될 수 있다.

## 결정 (Decision)

앱 이름은 **해달해달**로 한다.

## 결과 (Consequences)

- 앱인토스 콘솔 등록, 화면 문구, 문서에서 '해달해달'을 사용한다.
- 후속 작업: 루트 `package.json`의 `name`(`haedalpoint`)을 맞출지 결정이 필요하다.
