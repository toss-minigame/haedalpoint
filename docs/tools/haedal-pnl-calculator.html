해달 손익 계산기

광고 1회 수익, 환율, 낚시 속도를 바꾸면 사용자 유형별 하루·한 달 손익이 바로 계산돼요. 코드의 정책값(500마리 = 1원, 시간당 약 694마리, 해먹 5,000마리)이 기본으로 들어 있어요.

공통 가정

전체 사용자 평균

계산 방식과 가정

  • 속도 = 100% + 낚싯대 단계 × 단계당 % + 해달 친구 × 친구당 %. 보너스는 더해요.
  • 해먹 용량 = 기본 용량 × (100% + 해달 친구 × 친구당 % + 해먹 단계 × 단계당 %).
  • 저장 1회 물고기 = 저장 간격 동안 쌓인 양과 해먹 용량 중 작은 값. 간격이 길어도 용량을 넘기면 쌓이지 않아요.
  • 광고 수익 = (저장 횟수 × 광고가 뜬 비율 + 저장 외 광고 시청) × 광고 1회 수익. 저장 외 광고는 낚싯대 강화, 해먹 넓히기, 퀴즈, 출석 2배예요.
  • 광고 1회 수익은 토스 수수료를 뺀 순수익으로 가정했어요. 사용자 유형별 행동과 비중은 예시값이라 실제 데이터로 바꿔야 해요.
  • 최소 전환 단위는 아직 정해지지 않아 임의값(10원)을 넣었어요. 첫 전환까지 걸리는 시간 계산에만 쓰여요.
  • 이 계산기는 앱 코드와 별개예요. 값이 정해지면 정책값 파일에 따로 반영해요.
