# 원본 에셋

이미지 생성 AI로 만든 원본. 앱(`src/`)은 이 파일을 직접 쓰지 않고, 잡티를 지우고 크기를 줄여 잘라낸 복사본을 `src/shared/assets/` 에서 쓴다.
다시 다듬거나 재생성할 때 기준으로 쓴다.

| 원본                                                | 앱에서 쓰는 복사본                                                                                                                                 |
| --------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------- |
| `otter-moods/otter_1~6.png`                         | `src/shared/assets/otter/otter-happy.png` 한 장만 쓴다 (화면에 48px 로 나와 세로 144px 로 줄였다, 말풍선의 해달 얼굴). 나머지 표정 복사본은 지웠다 |
| `otter-fishing/*-1~5.png` (낚싯대를 쥔 낚시 프레임) | 없음 (지웠다)                                                                                                                                      |
| `otter-hammock-full.png` (물고기 양동이를 든 해달)  | 없음 (지웠다)                                                                                                                                      |

장면의 해달과 친구는 3D 모델(`design/otter-3d/`)로 그리게 되어, 낚시 프레임·양동이 해달·표정 복사본을 앱에서 지웠다.
지운 복사본은 알파 16 이하 잡티를 지우고 절반 크기로 줄여 그림 둘레 20px 여백만 남기고 자른 것이었다.
그 크기와 기준점(몸 가운데·발 끝·낚싯대 끝) 숫자는 웅덩이 자리와 낚시 영역을 정하는 데 계속 쓰여
`src/entities/otter/lib/scene/scene-state.ts` 의 `OTTER_SCENE_FRAMES` 에 남아 있다.
